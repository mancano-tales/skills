## 🔄 Sincronização & Automação (Git Hooks)

Verifique o alinhamento das skills a qualquer momento:
```bash
.\tools\sync-skills.ps1
```
Para aplicar atualizações e commitar com mensagem padronizada em Conventional Commits:
```bash
.\tools\sync-skills.ps1 -Apply all -Commit
```
